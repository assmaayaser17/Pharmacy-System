# صيدلية شفاء — متجر صيدلية إلكتروني (نسخة عرض للعميل)

متجر صيدلية كامل على نمط أمازون، موجّه للسوق السعودي، مبني بـ **Next.js 16 + TypeScript + Tailwind v4**، عربي RTL بالكامل، متجاوب مع الجوال، وببيانات تجريبية.

> الاسم والشعار والأرقام في `lib/config.ts` فقط، غيّرها لما العميل يعتمد هويته.

## التصميم

واجهة تجارة إلكترونية طبية بنمط القوالب الصيدلانية الحديثة: شريط علوي بكود الخصم، بحث مع قائمة «كل الأقسام»، قائمة أقسام جانبية مع بانر رئيسي متحرك وعروض جانبية، عروض اليوم بعدّاد وشريط مخزون، بانرات ملوّنة، تبويبات اختيارات الأسبوع، قوائم جديد/رائج/تخفيضات، ماركات، ونشرة بريدية. كل الرسومات SVG مرسومة بالكود، والألوان في `app/globals.css`.

## التشغيل

```bash
npm install
npm run dev          # http://localhost:3000
# أو للإنتاج
npm run build && npm start
```

البيانات تُحفظ تلقائيًا في `.data/db.json` (يُنشأ أول تشغيل). لإعادة الداتا لأصلها احذف مجلد `.data`.

## حسابات التجربة

| الدور | الجوال | رمز الدخول |
|---|---|---|
| عميل (عنده طلبات ومفضلة وعنوان) | `0501234567` | `1234` |
| مدير المتجر (لوحة `/admin`) | `0500000000` | `1234` |

أي رقم جوال سعودي جديد ينشئ حسابًا تلقائيًا بنفس الرمز.

## كيف صُمّم للسهولة (مستخدمون من كل المناطق، بمن فيهم القرى والهجر)

- أزرار وحقول كبيرة (٤٨px فأكثر للمس)، وزر **«كبّر الخط»** في أعلى الموقع.
- الدخول برقم الجوال ورمز فقط، **بدون كلمة مرور**.
- أول شاشة فيها ثلاثة خيارات كبيرة: ارفع وصفتك، اطلب بالواتساب، تصفّح.
- **زر واتساب واتصال عائم** في كل الصفحات، لمن لا يرتاح للتسوق من الموقع.
- شريط تنقل سفلي على الجوال، وزر الوصفة في المنتصف.
- صفحة دفع واحدة بخطوات مرقّمة وواضحة، مع أخطاء مكتوبة بلغة بسيطة.
- العنوان يدعم: مدينة، **قرية أو هجرة غير مدرجة**، وصف الموقع وأقرب معلم، العنوان الوطني (اختياري)، ومشاركة الموقع بضغطة.
- الدفع عند الاستلام متاح لكل المدن.
- كل الفلاتر تعمل بدون JavaScript (نماذج GET عادية).

| توصيل: سريع ساعتين، نفس اليوم، عادي للمملكة، استلام من الفرع (حسب المدينة) | ✅ |
| أدوية التبريد (إنسولين) لا تُشحن بالتوصيل العادي | ✅ |
| كوبونات خصم، ضريبة ١٥٪ مستخرجة من الإجمالي، فاتورة قابلة للطباعة | ✅ |

## هيكل المشروع

```
app/            الصفحات و API (App Router)
  api/          auth, orders, products, addresses, wishlist, prescriptions, admin ...
components/     الهيدر، السلة، كروت المنتجات، رسومات المنتجات (SVG بالكود)
lib/config.ts   الهوية، المدن، التوصيل، الدفع، الكوبونات
lib/seed.ts     الأقسام و٦٢ منتج تجريبي
lib/pricing.ts  حساب الشحن والخصم والضريبة (يُستخدم في الواجهة والسيرفر)
lib/db.ts       تخزين JSON تجريبي
```

## للانتقال إلى الإنتاج

1. **قاعدة البيانات**: استبدل `lib/db.ts` بـ PostgreSQL مع Prisma أو Drizzle. الأنواع في `lib/types.ts` جاهزة كأساس للجداول. (التخزين الحالي ملف JSON ولا يصلح للاستضافة العامة.)
2. **الدفع**: استبدل `MockGateway` في `app/checkout/CheckoutClient.tsx` ومسار `/api/orders` ببوابة مرخّصة من ساما مثل HyperPay أو Moyasar أو Tap أو Checkout.com، وهي تغطي مدى وApple Pay وstc pay وتمارا وتابي. تحقّق من الدفع من السيرفر (webhook) ولا تثق بالمتصفح.
3. **الدخول**: اربط `/api/auth/otp` بمزوّد رسائل سعودي (Unifonic أو Taqnyat)، أو بنفاذ.
4. **التوصيل**: اربط شركات الشحن (SMSA، ناقل، البريد السعودي، أرامكس) أو وسيطًا مثل OTO لحساب الأسعار وإصدار أرقام الشحنات الحقيقية. التوصيل السريع يحتاج مناديب الصيدلية أو شريك توصيل فوري.
5. **الوصفات**: اربط مراجعة الصيدلاني فعليًا (الآن تُقبل تلقائيًا للتجربة)، ويُفضّل التكامل مع منصة «وصفتي».
6. **الامتثال**: يلزم ترخيص وزارة الصحة / هيئة الغذاء والدواء للصيدلية الإلكترونية، والرقم الضريبي، وسياسة خصوصية متوافقة مع نظام حماية البيانات الشخصية، وصور المنتجات الحقيقية (الحالية رسومات SVG بديلة).
7. **الإنتاج**: ضع الملفات المرفوعة في تخزين سحابي مشفّر (S3 أو ما يعادله) بدل القرص المحلي، وفعّل HTTPS وحدّ معدل الطلبات على مسارات الدخول.

> أسماء الأدوية والماركات وأسعارها وأسماء العملاء في الداتا تجريبية بالكامل، وليست توصيات طبية.
